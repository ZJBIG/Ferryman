# 群岛航程与成长策划

本次实现依据原《可玩原型策划案》的运输、实时战斗、固定岗位、维修、报酬与出发岛强化，以及用户新增的分支航路、岛屿玩法、升级和探索线要求。借鉴《杀戮尖塔》的选路、风险收益、休整与局内构筑；操作仍为甲板上的移动、射击、飞踢和维修。

## 三回航程

新游戏从渡口空船启航。每回在海图选路，护送乘客到终点港。前两回抵达后点击「开始下一回」，返回渡口进入新海图，保留船况、金币、局内升级和成功送达的剧情乘客记录。第三回抵达终点港后点击「离港」，在外海迎战垃圾潮巨像。清除巨像与余留炸弹后结算整局，船毁时结算已获得报酬。

停靠邀约与接驳岛招募用简短对白交代出发地和目的地，由玩家决定是否载客。第一回首站遇到枪手猴，第二回前两站遇到维修师犀牛和神枪手猫头鹰。三位剧情乘客都去终点港，成功送达后在第三回离港时以原岗位回船援助。猫头鹰在对白中暗示想和犀牛保持距离，靠近犀牛时会避让。

普通邀约排除已在船的动物，同一种动物同时只能出现一次。乘客只在非海战、非精英的岛屿下船，达到目的地层数但选择战斗节点时继续随船，直到后续第一座可下客岛屿。终点港送达全部剩余乘客。地图在各支路对应的可下客岛屿右下角显示动物肖像。旧检查点中的重复动物恢复为该身份的第一位。

海图包含出发岛、六层各三个岛和最终岛，共二十个节点。一轮经过八座岛、七段海路。只能前往当前岛直接连接的下一层岛，不能跳层或回退。每层提供战斗与不同服务岛，岛屿和事件由同一种子确定；所有节点能通向终点。地图横向展开，图标错落排列，统一使用 56×56 显示范围并保留素材比例；整张羊皮纸随长图滚动。滚轮横移或右键拖动查看长图，当前岛改变时自动定位。航路只分叉或汇合，不交叉；相邻层保留同列连接，每对相邻列只保留一个方向的斜线。未走过的连接为褐色曲虚线，可选航线为蓝色曲虚线，实际走过的连接为深绿曲实线。乘客目的地按未来停靠层数保存，不因支路不可达而丢失。

每段海路先自由航行五秒。每波先在按种子错开后的出生点播放约 1.15 秒的上浮气泡和冒泡声，再从同一点刷怪。清完当前一波才预警下一波。第二日起，持续约 7–10 秒且同侧有空位的波次至多有一只远程海怪用原落水特效潜行换位，保留生命值并在重新浮出后继续攻击。海中怪物死亡时在落点溅起大水花并播放落水声，已登船的翻舷蟹留下有碰撞的残骸，由玩家像石块一样踢飞。普通海战清完最后一波后，等所有炸弹引爆或被清除，再开始五秒休整航行。普通石块和蟹残骸随船保留到后续关卡，玩家清除后才消失。航程结束或放弃时清理这些障碍。游戏时间、海面、船浪及角色行动始终照常进行，包括等待清怪和炸弹期间。各岛复用已有岛岸素材与 main 场景显示，活动通过现有羊皮纸和升级卡素材呈现。

每回前两段不生成精英岛。第一日前两段普通海战一波，第 3–6 段两波，后段精英和终点海战三波；第二、三日在此基础上各增加一波，每场最多四波。剧情航程的非战斗岛海战概率为 min(80%, 30% + 日期 × 12% + 当前段数 × 2.5%)，让后程持续承受压力，同时保留补给与活动。开场固定为三只礁螳螂，后续按三回累计段数解锁原有海怪。每波数量为 min(12, 3 + floor((累计段数 − 1) / 2) + 波次索引)，同时最多四种怪；翻舷蟹每波最多一只。战斗视野按最大波次所需空间扩大，保持全部海怪可见、外沿距船至少两单位及模型间距。终战仍为独立巨像战，三阶段暂缓。

战斗中由海鸥从屏幕外沿直线掠过甲板，每批可从任意方向飞来，每只海鸥只投放一个物体，多个物体由间隔飞行的多只海鸥投放。投放从现有普通障碍和炸弹事件中按种子抽取，物体从海鸥爪下沿弧线飞向甲板落点。每波生成后最多 1.2 秒启动首批，仍有活怪时继续投放；每波最多 2–4 批，批数在新一波重置。飞行结束后的等待时间随日期与段数从约 6.75 秒降至 3.5 秒；第一日前段每批一只海鸥，第二日起或后段每批两只。甲板空位不足时少投或跳过，障碍不另计事件或报酬。飞行中的目标区域及已落地炸弹都参与占位检查，投弹怪物与海鸥共用，清除后可再次使用该位置。

## 怪物特点

| 怪物 | 攻击特点 |
| --- | --- |
| 礁螳螂 | 每 1.5 秒射击，普通命中眩晕 1 秒 |
| 灯笼鱼 | 每 2.05 秒发射黄绿色推弹，优先瞄准未眩晕的船员，再攻击船长。命中沿弹道短距离推开并中断维修，眩晕时长为零 |
| 甲壳射手（海龟） | 160 HP，每 3 秒发射重弹，命中眩晕 2.5 秒；重复命中不延长 |
| 木桶寄居蟹 | 每 3 秒投弹，圆弹与炸药束蓄力时显示对应持物姿态，只伤船体 |
| 喷砂炮螺 | 每 1.6 秒射击，只攻击船体，每弹扣除 25 HP，命中船边显示实体受击特效 |
| 冻潮水母 | 命中减速 3 秒，移动、射击和维修速度变为 0.65，无眩晕 |
| 翻舷蟹 | 跃上甲板追击，优先船员；每 2.4 秒蓄力爪击，可躲开；挥击与命中均有特效。可被飞踢伤害，船上死亡留下可踢开的障碍 |
| 垃圾潮巨像 | 38,000 HP（原来的 100 倍），每 2.8 秒蓄力投放大体积垃圾炸弹，使用独立六帧蓄力表现；三阶段暂缓 |

| 岛屿 | 选择与收益 |

| 海战岛 | 航路发生普通海战，靠岸获得一次三选一升级 |
| 精英岛 | 较强海战、更高金币和特殊道具报酬，靠岸三选一 |
| 补给岛 | 恢复 300 船 HP，或领取 40 金币；只能选一次 |
| 船坞 | 免费三选一升级 |
| 集市 | 使用本轮游戏币点击卡片购买三种升级；点击离开集市，升级全满时直接跳过 |
| 接驳岛 | 选择战斗或维护岗位，和乘客对话后确认载客或谢绝。到站正常付运输报酬 |
| 宝藏岛 | 获得 60 金币、1 特殊道具与一次三选一升级 |
| 遗迹岛 | 船损 100 换 80 金币和 1 特殊道具；或免费获得三选一升级 |
| 终点港 | 送达全部剩余乘客。第一、二回从这里继续下一回，第三回从这里离港进入终战 |

补给直接恢复船 HP 时同步清理对应损伤进度，不能随后维修同一损伤重复回血。活动领取结果和待选升级立即记入区域检查点；恢复后不可再次领取。岛上操作不暂停游戏时间，也不禁止角色自由行动。

## 六类升级

每次免费奖励提供最多三个不同且未满级的选项，点击卡片后立即生效。乘客下船的游戏币和特殊道具报酬保持原规则；只有集市升级扣除本轮游戏币，其他地点（含永久整备）免费领取。局内升级每项最多五级，出发岛永久升级每项最多五级，两者等级相加计算属性。每次出航前只能领取一次永久整备，成功领取后按钮置灰。

| 升级 | 每级效果 |
| --- | --- |
| 火力 | 玩家伤害增加基础值的 20% |
| 连射 | 玩家射击间隔 = 基础间隔 / (1 + 等级 × 0.15) |
| 船体强化 | 最大船 HP +150，同时恢复新增的 150 HP |
| 快速维修 | 玩家维修速度增加基础值的 25% |
| 并行维修 | 玩家同时维修数量 +1，各点仍获得完整速度 |
| 维修范围 | 玩家切比雪夫维修范围 +1 格 |

集市三项升级价格仍为 50 × (当前等级 + 1) 游戏币，随检查点保存。局内成长在返家后清空，永久成长在创建新船时应用；永久领取写盘成功后才更新内存，钱包不变。保留旧存档版本，旧文件没有升级字段时按零级加载。

船长开局维修范围与维修船员相同，为 1 格；每秒修理 30 点，相当于标准维修船员 25 点的 120%，同时负责 1 处。战斗船员每次实际开火时独立判定 10% 暴击，伤害为该发本应造成伤害的 1.8 倍并取整；命中海怪显示更大的红色数字。

升级页使用整组居中的悬空卡片，图标置于卡片上方矩形内，下方显示作用。集市额外显示本轮金币余额、各卡购买价格与金币不足提示，点击离开集市可退出。可领取或可购买时点击整张卡片，满级项隐藏，全满则跳过。

战斗/维护 NPC 保持固定岗位，基础数值来自已有乘客配置。同船关系按当前乘客重算，离船即解除，不修改资源、不重复累积：猴与野猪同船时猴射速 +20%、野猪伤害 +20%；海狸与水獭双方维修 +30%；犀牛与海狸双方维修 +20%；野猪的炮声让水獭维修 −20%。维修关系按基础值相加，减速仍另外生效。猫头鹰靠近犀牛时保留停火和绕开。登船提示与同伴对话交代这些影响。每日开场、关键港口与上下客对话可点击继续或按空格、Enter 逐句推进，长按 Esc 0.8 秒跳过；海路闲聊定时播放，航程进入遇敌对白前清除闲聊。

## 表现与恢复

音频位于 `Assets/Ferryman/Resources/Audio`。港口、航行、普通海战和垃圾潮巨像终战各用对应音乐，成功与船毁播放短结尾。爆炸、投石、舰体损伤等效果按实际事件触发。引信从落地开始，炸弹移除时停止。维修声由破损点共享，无人继续修理时停止。终战加入援军号角、援军到场声和巨像聚合、碎裂音效。怪物预警和击败分别播放冒泡和落水声。

玩家射击播放枪口攻击特效，近战播放已交付挥击。怪物实际扣血时闪白、压扁回弹、弹散黄色碎粒，并向上显示扣血量。海中怪物败退时沿水花下沉。怪物子弹的显示尺寸乘 2，颜色区分短眩晕、重弹、推弹、减速和船体专攻。飞踢 NPC 保留击退，并附加正常眩晕时间的三分之一；重复踢击取 max(剩余眩晕时间, 本次短眩晕)。眩晕 NPC 让怪物子弹穿过，眩晕船长消耗子弹且免疫其效果。炸弹无碰撞器，近战按显示区域清除；爆炸复用现有烟尘。NPC 显示与碰撞在此前尺寸上同步再放大 1.3 倍，海怪显示为 1.56、巨像为 1.3；航程中按种子随机选择船上侧、右侧的可视位置，攻击和持物帧的最大外沿距船边至少 2 世界单位，模型之间留出间距，不能出现在船左侧或下侧。右侧非登船海怪的图像、碰撞与投弹点同步镜像。

右上角显示 `第x/3日`。遇敌时由一名船员和兔子船长简短交谈，空船时只显示船长。船长台词随日期和航段变化，船员反应随登船后的遇敌次数变化。读完或主动跳过对白后，怪物才开始冒泡预警并出场。岛上和海上都显示船长及有立绘船员的左侧肖像。海鸥沿用原图制作四帧拍翼，以 8 FPS 播放，身体与爪部位置保持固定。

旧线性路线和旧单回检查点继续按原流程通关，旧地图已走过的斜线在恢复时保留。分支检查点保存种子、路线、岛屿活动、登船决定、待选升级、船况、乘客、跨关障碍及收益。剧情航程另存当前回次和已送达的剧情乘客。开始下一回或终战离港时先保存入口，恢复时重播该海路并按送达记录安排援军。主动放弃和正常退出丢弃整局，强退恢复最近检查点，结算按航程 ID 去重。

## 验收

图生成确定、所有支路到达终点、禁止跳行；探索曲线随路径变化。各岛操作生效且只领取一次；金币/特殊道具不出现负值。六类升级改变实际伤害、射速、耐久及维修行为；永久购买与旧存档兼容。恢复已选择支路、待选奖励和升级后 HP，main 的场景 handle 不变。成功、船毁、放弃、返家和原有移动/战斗/维修回归保持通过。

Esc 短按在主页面和航程中打开暂停菜单，再按一次或点击继续关闭；对话期间松键判定短按，长按跳过后松键不再打开菜单。菜单暂停游戏时间、角色攻击和航程推进；音乐和音效可分别调节并保存。重新开始丢弃本轮，保留永久进度；航程内重开或退出先显示丢弃本轮的确认。
