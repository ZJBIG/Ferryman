# 群岛航程与成长策划

本次实现依据原《可玩原型策划案》的运输、实时战斗、固定岗位、维修、报酬与出发岛强化，以及用户新增的分支航路、岛屿玩法、升级和探索线要求。借鉴《杀戮尖塔》的选路、风险收益、休整与局内构筑；操作仍为甲板上的移动、射击、飞踢和维修。

## 一轮体验

出发岛选择首位乘客 → 在海图选择可达岛屿 → 航行与海路事件 → 岛屿活动与升级 → 选择下一岛 → 最终海战 → 送达与结算。

海图包含出发岛、六层各三个岛和最终岛，共二十个节点。一轮经过八座岛、七段海路。只能前往当前岛直接连接的下一层岛，不能跳层或回退。每行提供战斗与不同服务岛，路线和事件由同一种子确定；所有节点能通向终点。未走过的连接为曲虚线，实际走过的连接为曲实线，当前岛和可选岛有明确标记。乘客目的地按未来停靠层数保存，不因支路不可达而丢失。

每段海路事件前后各自由航行五秒。战斗、炸弹和落石期间游戏时间、海面、船浪及角色行动照常进行，清完当前波后进入下一波。后半程增加波次和敌人强度；精英航路给予更高报酬，终点前固定三波海战。各岛复用已有岛岸素材与 main 场景显示，活动通过现有羊皮纸和升级卡素材呈现。

## 岛屿

| 岛屿 | 选择与收益 |
| --- | --- |
| 海战岛 | 航路发生普通海战，靠岸获得一次三选一升级 |
| 精英岛 | 较强海战、更高金币和特殊道具报酬，靠岸三选一 |
| 补给岛 | 恢复 300 船 HP，或领取 40 金币；只能选一次 |
| 船坞 | 免费三选一升级 |
| 集市 | 使用本轮报酬购买三种升级；40 金币修复 200 HP；可直接离港 |
| 接驳岛 | 选择一位战斗或维护乘客，目的地为未来岛屿；到站正常付运输报酬 |
| 宝藏岛 | 获得 60 金币、1 特殊道具与一次三选一升级 |
| 遗迹岛 | 船损 100 换 80 金币和 1 特殊道具；或支付 40 金币获得三选一升级 |
| 最终岛 | 最终海战后送达全部剩余乘客，成功结算；船毁仍结算已获得报酬 |

补给直接恢复船 HP 时同步清理对应损伤进度，不能随后维修同一损伤重复回血。活动领取结果和待选升级立即记入区域检查点；恢复后不可再次领取。岛上操作不暂停游戏时间，也不禁止角色自由行动。

## 六类升级

每次免费奖励提供三个不同且未满级的选项，选一个后立即生效。金币与特殊道具来自航程报酬；集市消费从本轮待结算奖励中扣除。局内升级每项最多五级，出发岛永久升级每项最多五级，两者等级相加计算属性。

| 升级 | 每级效果 | 购买资源 |
| --- | --- | --- |
| 火力 | 玩家伤害增加基础值的 20% | 金币 |
| 连射 | 玩家射击间隔 = 基础间隔 / (1 + 等级 × 0.15) | 金币 |
| 船体强化 | 最大船 HP +150，同时恢复新增的 150 HP | 金币 |
| 快速维修 | 玩家维修速度增加基础值的 25% | 金币 |
| 并行维修 | 玩家同时维修数量 +1，各点仍获得完整速度 | 特殊道具 |
| 维修范围 | 玩家切比雪夫维修范围 +1 格 | 特殊道具 |

金币升级价格为 50 × (当前等级 + 1)，特殊升级价格为 1 × (当前等级 + 1)。出发岛只消费永久钱包并永久保存；集市只消费本轮钱包并随检查点保存。局内成长在返家后清空，永久成长在创建新船时应用。永久升级失败写盘时不扣钱、不修改已有钱包；保留旧存档版本，旧文件没有升级字段时按零级加载。

战斗/维护 NPC 保持原固定岗位；本轮先让玩家与船体六项成长完整生效，NPC 的岗位数值来自已有乘客配置。

## 表现与恢复

玩家攻击只显示目标命中反馈，取消自身挥击与枪口的多余特效。敌人保留原红色受击表现，其他实体使用已交付命中特效。

旧线性路线和旧检查点继续可用。分支检查点记录种子、所走节点、当前行程槽、已处理岛屿、待选升级、局内等级、船状态、乘客、收益；先应用升级后的船上限再恢复 HP。主动放弃和正常退出仍丢弃本轮，强退恢复最近检查点；结算继续按航程 ID 去重。

## 验收

图生成确定、所有支路到达终点、禁止跳行；探索曲线随路径变化。各岛操作生效且只领取一次；金币/特殊道具不出现负值。六类升级改变实际伤害、射速、耐久及维修行为；永久购买与旧存档兼容。恢复已选择支路、待选奖励和升级后 HP，main 的场景 handle 不变。成功、船毁、放弃、返家和原有移动/战斗/维修回归保持通过。
