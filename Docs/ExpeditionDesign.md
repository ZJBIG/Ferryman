# 群岛航程与成长策划

本次实现依据原《可玩原型策划案》的运输、实时战斗、固定岗位、维修、报酬与出发岛强化，以及用户新增的分支航路、岛屿玩法、升级和探索线要求。借鉴《杀戮尖塔》的选路、风险收益、休整与局内构筑；操作仍为甲板上的移动、射击、飞踢和维修。

## 一轮体验

出发岛选择首位乘客 → 在海图选择可达岛屿 → 航行与海路事件 → 岛屿活动与升级 → 选择下一岛 → 最终海战 → 送达与结算。

海图包含出发岛、六层各三个岛和最终岛，共二十个节点。一轮经过八座岛、七段海路。只能前往当前岛直接连接的下一层岛，不能跳层或回退。每层提供战斗与不同服务岛，岛屿和事件由同一种子确定；所有节点能通向终点。地图横向展开，图标错落排列，统一使用 56×56 显示范围并保留素材比例；羊皮纸直接裁剪原素材拼接，重叠接缝淡化，不新增贴图。滚轮横移或右键拖动查看长图，当前岛改变时自动定位。航路只分叉或汇合，不交叉；相邻层保留同列连接，每对相邻列只保留一个方向的斜线。未走过的连接为曲虚线，实际走过的连接为曲实线，当前岛和可选岛有明确标记。乘客目的地按未来停靠层数保存，不因支路不可达而丢失。

每段海路事件前后各自由航行五秒。战斗按时间推进，默认每 8 秒生成一波，上一波存活敌人保留，新敌人避开已有模型；最后一波的时间窗结束后继续航行，不要求杀完敌人或清理障碍。独立炸弹/落石事件投放后仅经过 0.85 秒的落物演出就进入后半段航行，不等待物品清除。障碍与敌人在当前海路内保留，离开区域时按原规则清理。游戏时间、海面、船浪及角色行动始终照常进行。各岛复用已有岛岸素材与 main 场景显示，活动通过现有羊皮纸和升级卡素材呈现。

前两段不生成精英岛，普通海战一波；第 3–6 段普通海战两波，后两段精英和终点海战三波。非战斗岛的随机海战概率按前两段、中两段、后段分别为 20%、30%、40%。敌人数随航程和波次逐步增加：默认两组各一只时，普通第 1–6 段总量依次为 2、2、5、7、8、8，终点三波共 15 只；敌人基础属性不改，精英增加数量并保留原高报酬。

战斗中复用现有落石及障碍素材从屏幕上方投放。首批在半个波次后投放，后续前两段、中两段、后段间隔分别为 12、9、7 秒，每场最多 1、2、3 批，每批分别为 1、1、2 个。落物按时间投放，不取决于敌人是否存活，也不阻塞波次或战斗结束；甲板空位不足时少投或跳过。只结算战斗报酬，不额外重复支付落物事件奖励。

## 岛屿

| 岛屿 | 选择与收益 |
| --- | --- |
| 海战岛 | 航路发生普通海战，靠岸获得一次三选一升级 |
| 精英岛 | 较强海战、更高金币和特殊道具报酬，靠岸三选一 |
| 补给岛 | 恢复 300 船 HP，或领取 40 金币；只能选一次 |
| 船坞 | 免费三选一升级 |
| 集市 | 使用本轮游戏币点击卡片购买三种升级；按 Esc 退出，升级全满时直接跳过 |
| 接驳岛 | 选择一位战斗或维护乘客，目的地为未来岛屿；到站正常付运输报酬 |
| 宝藏岛 | 获得 60 金币、1 特殊道具与一次三选一升级 |
| 遗迹岛 | 船损 100 换 80 金币和 1 特殊道具；或免费获得三选一升级 |
| 最终岛 | 最终海战后送达全部剩余乘客，成功结算；船毁仍结算已获得报酬 |

补给直接恢复船 HP 时同步清理对应损伤进度，不能随后维修同一损伤重复回血。活动领取结果和待选升级立即记入区域检查点；恢复后不可再次领取。岛上操作不暂停游戏时间，也不禁止角色自由行动。

## 六类升级

每次免费奖励提供最多三个不同且未满级的选项，点击卡片后立即生效。乘客下船的游戏币和特殊道具报酬保持原规则；只有集市升级扣除本轮游戏币，其他地点（含永久整备）免费领取。局内升级每项最多五级，出发岛永久升级每项最多五级，两者等级相加计算属性。

| 升级 | 每级效果 |
| --- | --- |
| 火力 | 玩家伤害增加基础值的 20% |
| 连射 | 玩家射击间隔 = 基础间隔 / (1 + 等级 × 0.15) |
| 船体强化 | 最大船 HP +150，同时恢复新增的 150 HP |
| 快速维修 | 玩家维修速度增加基础值的 25% |
| 并行维修 | 玩家同时维修数量 +1，各点仍获得完整速度 |
| 维修范围 | 玩家切比雪夫维修范围 +1 格 |

集市三项升级价格仍为 50 × (当前等级 + 1) 游戏币，随检查点保存。局内成长在返家后清空，永久成长在创建新船时应用；永久领取写盘成功后才更新内存，钱包不变。保留旧存档版本，旧文件没有升级字段时按零级加载。

升级页只显示现有素材组成的悬空卡片，整组水平隔开并在画面居中；图标居中置于卡片上方矩形内，下方只写作用，不显示额外背景、标题、价格、等级或领取按钮。整张卡片可点击，满级项不显示，全满则跳过。只有集市允许按 Esc 退出，其他升级页无离开或返回入口。

战斗/维护 NPC 保持原固定岗位；本轮先让玩家与船体六项成长完整生效，NPC 的岗位数值来自已有乘客配置。

## 表现与恢复

玩家射击播放现有枪口攻击特效，近战播放已交付挥击；目标接触位置显示命中反馈，敌人保留原红色受击表现。炸弹无碰撞器，近战按显示区域清除；爆炸复用现有烟尘。海怪模型显示放大 1.2 倍，航程中按种子随机选择船上侧、右侧的可视位置，模型之间留出间距，不能出现在船左侧或下侧。

旧线性路线和旧检查点继续可用，旧地图已走过的斜线在恢复时保留，并移除与其交叉的连接。分支检查点记录种子、所走节点、当前行程槽、已处理岛屿、待选升级、局内等级、船状态、乘客、收益；先应用升级后的船上限再恢复 HP。主动放弃和正常退出仍丢弃本轮，强退恢复最近检查点；结算继续按航程 ID 去重。

## 验收

图生成确定、所有支路到达终点、禁止跳行；探索曲线随路径变化。各岛操作生效且只领取一次；金币/特殊道具不出现负值。六类升级改变实际伤害、射速、耐久及维修行为；永久购买与旧存档兼容。恢复已选择支路、待选奖励和升级后 HP，main 的场景 handle 不变。成功、船毁、放弃、返家和原有移动/战斗/维修回归保持通过。
