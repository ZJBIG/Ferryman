# 《摆渡人》剧情与对白

兔子船长第一天开渡船，想按船票上写的时间把船开到终点港。三天里，同样的废桶从礁口出现，到外港卷进巨像，最后由玩家拖回港务棚。水道重新开放后，孩子终于能用上那张去看姥姥的船票。

## 三日主线

| 日期 | 必经停靠点 | 船长的决定 |
| --- | --- | --- |
| 第一天 | 出发岛交代首航和基本操作；第 1 站提到守礁的海怪和堵路的废网；第 3 站认出港口旧桶「东仓七号」；终点港对上货号，灯塔目击黑影卷回废桶。等船的孩子把船票留了下来。 | 把货号记进日志，从潮水和废网查起。 |
| 第二天 | 出发岛确认退潮时礁口水位异常；第 3 站听巡海员讲灯笼鱼怎样护小鱼；第 5 站听灯塔守望员讲巡船捞网；终点港交代闸轴缠网，开闸后废料在外港被黑影截住。 | 照常跑完第三天的航班，再专程出港清水道。 |
| 第三天 | 出发岛交代堤坝险情；第 3 站确认鱼群用的窄水道与回收安排；终点港结束当日客运，灯塔命名垃圾潮巨像，船长请求出港。 | 给鱼群留出近礁水道，把散开的废料拖回岸上。 |

货号、鱼群、闸轴和回收安排按停靠层出现，每条合法航线都会经过。守礁与捞网由角色转述，普通战斗仍按海图生成。船长根据听见和亲历的线索逐步改变判断。

## 上船的人

| 人物 | 说话方式与分工 |
| --- | --- |
| 兔子船长 | 习惯说到站时间、甲板和日志。第一天紧张，第二天会问清水下发生了什么，第三天开始主动安排航线和收缆。 |
| 阿洛 | 话短，先动起来。踢开登船敌人和附近的炸弹，空档射击。 |
| 阿沅 | 常请人再看一眼，从水流和鱼群行为判断。标记海怪，船长命中后消耗标记并追加伤害。 |
| 闻岬 | 用次数、水位和位置说话，习惯核对。优先瞄准准备投掷的海怪。 |
| 阿榆 | 习惯说手上的活该由谁接。船长开始维修或被眩晕时，短时接火。阿榆有自己的动作与立绘。 |

每局从四位特殊船员中抽三位，每天首航一位从水里跃上船。余下的一位在最终出港时登船，四人一起迎战巨像。登场见闻随日期与人选变化。三个位置分别提供漂流异常、礁区线索和外港情况，必经停靠点负责证实。甲板拥挤时船员等到有空位再上甲板。

枪手猴去替妹妹守灯塔，维修师犀牛去潮闸送工具，神枪手猫头鹰去交潮线图。三人分别在第一日首站和第二日前两站邀约。确认载客后，用一句话交代在船上的位置或打算，搭档在场时补一句来回。到站各有一句道别。成功送达者在终战返场，以原岗位帮忙。选择谢绝时，玩家照常选择岛屿活动，由港务和灯塔提供必要线索。

| 同船关系 | 实际效果 |
| --- | --- |
| 枪手猴 + 炮手野猪 | 猴子射速 +20%，野猪伤害 +20% |
| 木匠海狸 + 捻缝师水獭 | 双方维修速度 +30% |
| 维修师犀牛 + 木匠海狸 | 双方维修速度 +20% |
| 炮手野猪 + 捻缝师水獭 | 水獭容易被炮声打断，维修速度 -20% |
| 维修师犀牛 + 神枪手猫头鹰 | 猫头鹰靠近犀牛会停火避让，拉开距离后恢复 |

## 终战与结局

玩家在第三日终点港用金币整备，点击「离港迎战」后沿灯塔的号角进入外港。已送达的剧情乘客回船，第四位特殊船员也加入。战前简报交代清理投掷物、召来的海怪和核心窗口。巨像依次单投、双投和最多三投，召回的海怪也逐波增加，最后一阶段投完才短暂露出核心。

击倒巨像并处理余弹后，船长再次认出「东仓七号」。海鸥把回收袋投到船尾，玩家到收缆点按 F 或点击按钮，逐件收起三份废料，再扎袋系缆。拖行开始时，最后登船且实际在甲板上的同行者说一句，空船时由船长接话。

返港后，港务接缆并把货号销账，之后的返航船只也要到这里交废网、空桶。孩子拿出第一天留存的船票，船长确认给她留了明早第一班的座位。航程在码头结算，下一班船留给结尾对白。

## 对白节奏与操作

- 每日开场、关键停靠点、首次交战和新乘客首次遇敌用手动对白。一般停靠直接开放岛屿活动，其余普通海战直接进入冒泡预警。
- 航行只在少量固定海段自动播一句闲聊，战后拖行也用单句，过场时清除字幕。选项和相关操作由现有界面提示。
- 关键对白可点「继续」，或按空格、Enter 推进；长按 Esc 0.8 秒跳过。终战失败或强退沿用航程结算与终战入口检查点规则。
